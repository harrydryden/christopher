# CV and Experience performance review — 12 November 2026

This change targets repeated work on CV workspace loads, Experience loads and career-to-CV projection. It builds on PR #143; it does not replace that PR's wider journey work.

## Implemented

- CV workspace: overlap independent reads after ownership has been established. Resolve role-description versions in one query and compute a draft's targeting view once for both consumers. Preserve the earlier-description notice only for an actually older source.
- Experience landing: fetch only the latest library version. Remove unused evidence scoring, review signatures, open evidence drafts and library parsing that were being prepared for a component which now only linked to About you. Remove the wrapper and its link-only test. Import progress polling remains; evidence review remains on its dedicated route.
- Career history: return change IDs, revisions, changed object IDs, undo relationships and dates. Do not transfer entire before/after/operations snapshots to the application just to render a history summary. Keep snapshots stored for undo.
- Career projection: index usable and disputed assertions by record once and compute relevance once per eligible record before sorting. Preserve relevance weights, perspective boosts, capacity, confidentiality, conflict decisions and deterministic tie-breaks.
- Undo: a new regression exposed incorrectly encoded SQL arrays when undoing a compound record/assertion/link creation. Use typed exclusion predicates, including their correct empty-list behaviour, and compute the original object sets once.

No new caching layer, dependencies, migrations or client state model. Per-account reads retain account scope. Ordinary draft edits still save without AI reprocessing.

### Measurement implementation

`measureCvPdf` shares every layout operation with export, including fonts, headings, industry pills, wrapping, page breaks and footers. Once layout is complete it destroys the disposable stream instead of embedding font subsets and serialising a PDF. Page count and layout reports are checked against export for both supported fonts at 11pt and 12pt, including an over-limit document. The fitter and worker's page-only checks use this path. Actual PDF downloads are unchanged.

Font geometry is cached by font and body size (six supported combinations). Values contain no CV text or account data and callers receive copies. Different font sizes retain different budgets.

Reproduce the local layout diagnostic with `node --import tsx scripts/benchmark-cv-layout.mjs`. Five roles, twenty bullets, twenty alternating measured rounds after four warm-ups:

| Font | Full PDF median | Measurement median | File buffer avoided per measurement |
| --- | ---: | ---: | ---: |
| Arial | 19.45 ms | 16.16 ms | 19,048 bytes |
| Course of Life | 1.66 ms | 1.54 ms | 2,788 bytes |

These are local CPU observations, approximately 17% and 7% lower respectively; they are not whole-build latency claims. The avoided file buffer is not a measurement of total peak memory. Compression alone produced little improvement, so measurement also avoids file finalisation. Font parsing and actual layout remain necessary.

### Token usage and remaining opportunities

Unchanged inline suggestions now incur one author call instead of an author plus verifier call. The verifier consumes zero tokens for this case; tests assert zero provider calls and zero usage records. This does not make edited proposals exempt from verification, alter the user's allowance policy or bypass source freshness checks.

More aggressive token reductions need quality evidence: removing the original advert, shortening evidence, narrowing claim-only batches or switching author models can affect phrasing, factual coverage and provider cache behaviour. They are not implemented as blind truncation. The current shared prefixes and scoped retries are already valuable. Before changing them, compare uncached/cached input tokens, output tokens, retry rate, time to first usable CV, page-fit rewrites and evaluation outcomes on the live qualification corpus. No live provider spend or changed assessment standard is part of this pass.
